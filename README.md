# Students AI Usage Analysis Dashboard – Power BI

## Project Overview
This project analyzes students' AI tool usage and its relationship with academic performance using Power BI.

## Objectives
- To understand students' AI tool usage patterns.
- To analyze grade improvement among students.
- To explore the relationship between AI usage and academic performance.

## Data Cleaning
- Cleaned and transformed the dataset using Power Query.

## Dashboard Features
- Interactive charts and visualizations
- KPI cards
- Slicers for filtering data
- Grade improvement analysis

## Tools Used
- Microsoft Power BI
- Power Query

## Key Outcome
Developed an interactive dashboard to present insights into students' AI usage and academic performance.# Student-Ai-usage-dashboard--by-using-powerbi
